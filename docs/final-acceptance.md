# 依旧沉淀 · 验收标准

当前验收以 [product-baseline.md](product-baseline.md) 描述的产品方向为准。历史 v1 验收规则移入文末“归档”一节。

## 一、最终验收标准（创作主线）

至少使用 **3 个真实娱乐 / 泛娱乐营销号选题**进行测试，必须满足：

| # | 验收项 | 标准 |
| --- | --- | --- |
| 1 | 首屏 | 打开工作台后 10 秒内可以输入选题 |
| 2 | 默认首页 | 默认首页是创作，不是 Skill 管理 |
| 3 | 研究优先 | 输入选题后首先得到研究结果 |
| 4 | 事实区分 | 已确认事实和存疑信息明显区分 |
| 5 | 角度顺序 | 用户先选 Angle，再匹配 Structure |
| 6 | 定向素材 | Angle 选定后进行第二次定向素材研究 |
| 7 | 素材控制 | 用户能明确选择哪些 Material 进入正文 |
| 8 | 无 Skill 可用 | 没有任何现成 Skill 时也能完成生成 |
| 9 | 资产分离 | 结构和 Reference Script 相互独立 |
| 10 | 完整成稿 | AI 一次生成完整可编辑稿，而不是占位模板 |
| 11 | 生成阶段去 AI 味 | human-writing 在生成阶段生效 |
| 12 | 审稿标注 | shuorenhua 默认用于 annotation，而不是整篇洗稿 |
| 13 | 局部改写 | AI 味问题可以直接触发现有局部改写 |
| 14 | 风险识别 | 事实 / 隐私 / 攻击 / 平台风险能够被识别 |
| 15 | 不阻塞 | GitHub / Codex Sync / Skill Gate 不阻塞普通创作 |
| 16 | 工厂可用 | 原有 Skill 工厂仍然能正常使用 |
| 17 | 体验 | 整个流程明显比当前版本减少无意义点击和配置 |

## 二、Phase 验收

每完成一个 Phase 就地验证，不允许六个 Phase 全改完才测试。使用真实营销号选题跑完整路径。

| Phase | 验收 |
| --- | --- |
| Phase 1 信息架构 | 打开工作台 10 秒内可输入选题；旧 Skill 工厂入口可达；现有发布 / 诊断能力不丢失 |
| Phase 2 研究 + 角度 | 输入选题后首先得到研究结果；事实与存疑区分；4–8 个角度可人工选择或自定义 |
| Phase 3 素材 + 结构 | 角度后二次定向研究；Material 可勾选；无 Skill 时用通用结构继续 |
| Phase 4 完整成稿 | 一次生成完整可编辑稿；无占位符；材料不足时明确标注 |
| Phase 5 去 AI 味 | annotation 标注可用；标注可直接触发局部改写；无整篇自动洗稿 |
| Phase 6 Reference Library | Reference 检索可用；结构与参考稿独立；不复制事实与句子 |

## 三、数据与安全底线

- API Key 只通过本机 UI 或当前 shell 环境传入，不写入仓库文件。
- 状态报告只显示是否配置和脱敏提示，不输出明文密钥。
- 原始视频、音频、关键帧仅临时保存；长期保留转写、分析、结构资产、稿件与版本。
- 不抓取或分析未授权、非公开、不可合法使用的第三方内容。
- 不把离线 fallback 输出伪装成真实模型输出。

## 四、归档：v1 最终验收（2026-08）

以下为 v1 阶段验收规则，仅作历史追溯。

v1 最后三道门禁由 `verify:workbench:final` 同时满足才算完成：

| 门禁 | 必须满足 |
| --- | --- |
| 代码闭环 | `acceptance`、依赖、LLM 离线 smoke、UI、前端构建、Python 编译均通过 |
| 视频模型链路 | `video-smoke` 报告通过 |
| 真实抖音链接 | 用授权的公开链接完成免登录真实下载验证 |
| 真实 LLM | 已配置真实 API Key/API Base/模型，并通过结构化 smoke |
| 人工复核 | 10 条热点脚本全部满足可拍、非纯复述、结构清晰、风控通过 |

推荐操作顺序（历史）：

1. 启动工作台 `npm run workbench:start`，打开 `http://127.0.0.1:5173/`。
2. 进入 `审核导出 -> 本机凭证配置` 设置 LLM 模式并应用本机凭证。
3. 进入 `审核导出 -> 人审记录` 生成人审模板，逐条勾选可拍、非复述、结构清晰、风险通过。
4. 点击 `执行真实门禁`，或运行 `npm run verify:workbench:final -- --link '...'`。

v1 状态报告输出：

```text
evals/workbench/status-report.md
evals/workbench/status-report.json
```

> 说明：v1 门禁面板、人审模板和凭证入口仍然保留，但它们属于 Skill 工厂 / 系统诊断的高级能力，不再是创作主线的验收前置条件。
