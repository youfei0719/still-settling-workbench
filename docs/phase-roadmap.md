# 依旧沉淀 v1 执行边界

## 产品目标

本机/内网的内容生产工作台。只验证这一条闭环：

```text
链接、视频或文本输入
-> 可分析文本
-> 结构分析
-> 模板沉淀
-> 热点反推脚本
-> 风控
-> Markdown/JSON 导出
```

主导航固定为五页：链接分析台、分析工作区、模板资产库、热点反推室、审核导出。

## 已完成

| 能力 | 当前证据 |
| --- | --- |
| 文本闭环 | 纯文本、字幕、转写文本可进入分析、模板、热点生成、风控和导出。 |
| 视频闭环 | 自有中文口播和硬字幕样例已验证上传、FFmpeg、FunASR、PaddleOCR、统一文本、结构分析、脚本生成和临时媒体清理。 |
| 模型稳定性 | ASR/OCR 在独立 `.venv-model` 工作进程执行；默认不回退到 macOS 系统 Python，避免原生库异常触发崩溃弹窗。 |
| 链接兜底 | `douyin-downloader` 已接入；公开短链以免登录方式自动重试。确实无法获得媒体时才转为视频、字幕或纯文本输入。 |
| 输出约束 | LLM 层支持 LiteLLM + Instructor/Pydantic；离线模式不伪装为真实模型输出。 |
| 数据边界 | 原始视频、音频和 OCR 帧在统一文本成功后自动清理；长期保留分析、模板和脚本记录。 |
| PostgreSQL / Docker | Docker PostgreSQL 已完成迁移、读写和 API 重启持久化验证。 |
| UI 回归 | 桌面与移动端 4 项 Playwright 工作台测试通过，覆盖五页导航和文本到导出闭环。 |
| 外部门禁 | 审核导出页已接入真实链接、真实 LLM、人审质量三项门禁状态和人审模板生成。 |

## 剩余验收任务

| 优先级 | 任务 | 完成标准 | 当前阻塞 |
| --- | --- | --- | --- |
| P0 | 真实授权链接验收 | 一条公开且有权限的抖音链接完成下载、转写/OCR、分析与脚本生成。 | 已有测试链接；不要求本机登录态。 |
| P0 | 真实 ASR/OCR 验收 | 一条短视频通过 FunASR/PaddleOCR 生成可分析文本，API 保持健康。 | 已用自有中文口播和硬字幕样例通过；后续可继续用更多授权视频复测。 |
| P0 | 真实模型质量验收 | 以配置好的模型完成分析和热点生成，输出通过 schema，并由人工判断可拍摄、非复述、结构清晰。 | 需要本机环境变量中的模型网关配置。 |
| P1 | 样本验收 | 30 条授权样本至少 80% 从输入完成到脚本分析；10 个热点各输出至少 3 个不同角度。 | 需要授权样本与人工评价。 |
| P1 | 风控验收 | 隐私、谣言、人身攻击、恶意引战、低俗擦边、未成年人敏感内容被标记或改写。 | 可用现有回归样本持续验证。 |

## 明确不继续做

- 不新增样本资产库、批量采集、交接包、导出历史、运营确认清单等后台管理功能。
- 不自动发布、不绑定 UID、不做冲榜、数据回收或客户结案。
- 不将向量库或账号资产中心作为当前核心验收的前置条件；Docker PostgreSQL 已完成本机验证。
- 不对未授权的第三方抖音内容做抓取或分析验证。

## 当前执行顺序

1. 用 `npm run model-env:workbench` 准备独立 ASR/OCR 模型环境。
2. 用已有自有视频持续回归视频提取与临时文件清理。
3. 获得授权链接后做一次真实链接端到端验证。
4. 配置真实 LLM 后对同一批样本做人审质量验收。
5. 达到样本成功率和脚本质量标准后，v1 才算完成。
