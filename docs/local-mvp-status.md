# 本地 MVP 当前状态

## 可用主链路

当前网站是本机/内网的内部内容生产工作台，主导航固定为五页：

1. 链接分析台：输入链接，或上传视频、字幕、转写文本、纯文本。
2. 分析工作区：查看钩子、冲突、结构、情绪、结尾和模板建议。
3. 模板资产库：筛选、查看、复盘和套用可复用脚本结构。
4. 热点反推室：输入热点，生成至少 3 个不同角度的可拍摄脚本。
5. 审核导出：编辑单条生产单，检查风控，导出 Markdown 或 JSON。

## 当前边界

- 默认使用 `offline` 结构化模式；LiteLLM 和 Instructor 已安装并可切换到真实模型，但当前没有把离线结果伪装为真实模型调用。
- `scripts/dev-workbench-api.py` 通过项目虚拟环境启动，默认优先连接 PostgreSQL；数据库不可用时自动降级。模型推理通过独立 `.venv-model` 工作进程完成；未显式配置模型 Python 时，不自动调用 macOS 系统 Python。
- `douyin-downloader` 已配置并可由链接任务调用；公开短链会在一次提交内免登录自动重试。若平台仍未返回媒体，系统会明确标记为 `public_access_unavailable`，不要求用户配置 Cookie。
- 原始视频只临时保存；长期保留转写、分析、模板和生成脚本。
- 不做自动发布、账号 UID 绑定、冲榜、数据回收、客户结案或样本资产管理后台。
